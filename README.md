# Лесная переправа

Первый технический прототип для Godot 4. Открыть project.godot и нажать F6 на main.tscn либо F5.

Лес, растения, три противника и разговор реализованы условными геометрическими формами. Музыки, звуков птиц, исторических моделей, эффектов заклинаний, сохранения и анимаций пока нет. Религиозные и исторические признаки не кодируются внешностью временных фигур.

Технический бой и сбор нужны для проверки размеров сцены и управления. Заморозка длится 3 секунды, растения восстанавливают 10% максимального запаса. Перед выпуском требуется проверка в Godot и замена временной графики. Начальное управление WASD временное; управление щелчком будет отдельным следующим шагом.

Проверен запуск в Godot 4.7.2: импорт, 120 кадров headless и графический OpenGL запуск без ошибок. Полное прохождение не проверено.

Текстуры Fab не включены в репозиторий. Без них используются однотонные материалы. Собственный лицензированный материал можно разместить в assets/materials/bark/bark.tres.

Управление: WASD, пробел — атака, Shift — щит; Q/E/R — магия; 1/2 — лечение и мана.
